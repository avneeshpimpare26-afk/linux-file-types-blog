# Exploring Linux File Types Using `ls -l` and `file`

A beginner-friendly technical blog created for the Shell Scripting CCE 2 activity (Module 2).

## Files in this project

- `index.html` – blog content and page structure
- `style.css` – colours, layout and responsive styling
- `script.js` – mobile navigation, footer year and copy button

## Run the website on your computer

1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Publish with GitHub Pages

1. Sign in to GitHub and open the college repository where the blog should be published. If your faculty has asked you to create a separate repository, create one with a suitable name first.
2. Upload `index.html`, `style.css`, `script.js` and this `README.md` to the repository's required folder.
3. Make sure `index.html` is in the folder that GitHub Pages will publish.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the branch instructed by your college (commonly `main`) and the correct folder (commonly `/root`), then save.
7. Wait for GitHub Pages to finish deploying. The Pages section will show the published website URL.
8. Open that URL and test the navigation and page sections. Share the published URL with your faculty.

> If your college already has a specific repository structure or publishing workflow, follow that instruction instead of changing the repository settings.

## Topic coverage

The blog explains the seven file-type symbols (`-`, `d`, `l`, `c`, `b`, `p`, `s`), the permission groups and `r`, `w`, `x` characters, the `ls -l` and `file` commands, a nine-step terminal demonstration, real-world applications, learning outcomes and references.
