01 / GETTING STARTED

Why do Linux file types matter?

Linux provides many useful commands through its terminal. When managing files, it is helpful to know whether an item is a regular file, directory, symbolic link, device file or another type.

The ls -l command displays detailed information, including a file type indicator and permissions. The file command gives a more descriptive identification based on the file's contents.

03 / LINUX BASICS

Understanding Linux file types

The first character in the ls -l output indicates the type of item. Here are the common symbols.

SymbolFile typeMeaning
-Regular fileText, image, document, program or other file.
dDirectoryA folder that contains files and other directories.
lSymbolic linkA shortcut-like link to another path.
cCharacter deviceA device that works with a stream of bytes.
bBlock deviceA device that reads or writes data in fixed-size blocks.
pNamed pipe (FIFO)Used for communication between processes.
sSocketUsed for communication between processes or across a network.
Quick tip: If the first character is d, it is a directory. If it is -, it is a regular file.
04 / COMMAND 1

Using the ls command

The ls command lists the contents of a directory. It displays the names of files and folders in the current location.

When we use ls -l, it displays the information in long format. This includes the file type, permissions, owner, group, size, modification date and file name.

Terminal

ubuntu@ubuntu:~$ ls

Desktop   Documents   Downloads

Music   Pictures   notes.txt


ubuntu@ubuntu:~$ ls -l

-rw-r--r-- 1 ubuntu ubuntu 24 notes.txt

drwxr-xr-x 2 ubuntu ubuntu 60 projects

05 / FILE PERMISSIONS

Read, write and execute

The next nine characters in a long listing show permissions in three groups: owner, group and others.

-rw-r--r--
Owner

Permissions for the user who owns the file.

Group

Permissions for users in the file's group.

Others

Permissions for other users.

r

Read

Allows a user to view or read the file.

w

Write

Allows a user to make changes to the file.

x

Execute

Allows a user to run the file as a program.

Example: -rw-r--r-- means the owner has read and write permission, while the group and others have read permission.
Terminal

ubuntu@ubuntu:~$ file notes.txt

notes.txt: ASCII text

ubuntu@ubuntu:~$ file hello.sh

hello.sh: Bourne-Again shell script, ASCII text executable

06 / COMMAND 2

What does the file command do?

The file command is used with a filename. It examines information and recognisable content patterns to identify the file's type or format.

This is useful when a file extension is missing or does not accurately describe the file. It helps us understand what kind of file we are working with.

file filename
07 / PRACTICAL IMPLEMENTATION

Let's try it in the terminal

The following steps create sample files and then inspect them using ls -l and file.

1

Start the shell script

#!/bin/bash

This line specifies that the script should be executed using the Bash shell.

2

Create a directory

mkdir filetype

Creates a new directory named filetype to store the sample items.

3

Enter the directory

cd filetype

Changes the current working directory to filetype.

4

Create a text file

echo 'This is a text file.' > notes.txt

Creates notes.txt and writes the given text into it. The > operator redirects output into the file.

5

Create a shell script file

printf '#!/bin/bash\necho "Hello from script"\n' > hello.sh

Creates hello.sh with a Bash instruction and a simple message.

6

Give execute permission

chmod +x hello.sh

Adds execute permission to the shell script.

7

Create a subdirectory

mkdir projects

Creates another directory named projects inside filetype.

8

Display detailed file information

ls -l

Displays the file type indicator, permissions, ownership, size, modification date and name.

9

Identify the file types

file notes.txt hello.sh projects

Examines the specified items and displays information about their file types or contents.

Sample output

-rwxr-xr-x  hello.sh
-rw-r--r--  notes.txt
drwxr-xr-x  projects

notes.txt: ASCII text
hello.sh: Bourne-Again shell script, ASCII text executable
projects: directory

The exact owner, group, size and date values may differ on your system.
